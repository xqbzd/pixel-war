# pixel war

a build-drive-fight game like Robocraft or Crossout. made by godot with llm,
i don't understand its code very much. if you like this game please give me advice and fix its bugs.

玩法一句话：**一个体素载具沙盒** —— 在建造模式里用方块拼一台车（装核心、装轮轴/轮胎、装机枪），
然后开进测试场跑赛道、打靶子。

> 现在还是**开发中的原型**：核心玩法（建造 / 驾驶 / 开火 / 毁伤）都能用，但还没有关卡目标、
> 没有存档 UI、美术基本都是体素占位。

## 怎么玩

* **Web 版**：等发布后直接点仓库首页的链接（GitHub Pages），浏览器里就能玩。
* **Windows 版**：到 [Releases](../../releases) 下载 zip，解压后运行里面的 exe。
* **从源码跑**：见下面「从源码运行」。

游戏流程：主界面 →「进入载具编辑」拼一台车 → ESC →「去测试场（先保存）」→ 开车、开火。
主界面会**记住上次选中的机库**（切场景回来、退出重进都还是那一台）。

对战场地的**掩体和出生点**直接在 **Godot 编辑器**里摆：打开 scenes/battle_arena.tscn，`Cover` 里的石头和 `Spawns` 里的出生点 Marker 都能用 W/R/E 拖、转、缩放，保存后进战局就生效（细节见 docs/parts-pipeline.md）。
想打仗：主界面「进入战斗」= **人机对战 5v5**（你 + 4 个人机队友 vs 5 个人机敌人）。
进测试场要求：**装了核心，而且所有零件都和核心连在一起**（HUD 上会写清楚差什么）。

## 操作

**建造模式**

| 操作 | 作用 |
| --- | --- |
| 左键 | 放置手上的零件（贴着别的零件/地面的连接面） |
| 右键 | 拆除瞄准的零件（镜像开着时会连镜像位置那件一起拆） |
| `1`~`9` | 选物品栏里的零件 |
| `R` | 换放置朝向（绕连接面转 90°） |
| `M` | 开/关**镜像建造**（左右对称） |
| `[` `]` | 移动对称面（每次半格） |
| `O` | 显示重心 |
| WASD / 空格 / Shift | 飞相机（空格上升、Shift 下降） |
| ESC | 菜单（保存 / 拉载具列表 / 游戏设置 / 去测试场） |

**测试场**

| 操作 | 作用 |
| --- | --- |
| `W` `S` | 油门 / 反向（反方向键 = 先自动刹车，停稳再倒车） |
| `A` `D` | 转向 |
| 鼠标 | 环视 + 瞄准（准星是屏幕中心那颗十字）；灵敏度自动跟着视野/倍率缩放 |
| 左键 / 空格 | 开火（按住连发，射速由部件文件的 rpm 管） |
| 右键（按住） | 开镜：出现镜筒遮罩 + 右侧倍率滑条，视野 =「平时视野 ÷ 倍率」，松开就回平时视野 |
| 滚轮 | 调**视野 FOV**（相机和车的距离固定，不拉远拉近）：**30°~53°**，默认 53°；开镜时调 2~16 倍，倍率本场记住 |
| `O` | 显示重心 |
| `[` `]` | 缩放场地 |
| `↑↓←→` / `<` `>` | 推车 / 升降（调出生点用） |
| ESC | 暂停菜单（返回战斗 / 游戏设置 / 自爆 / 返回主界面） |

**人机对战**（主界面「进入战斗」→ 配置界面）

点「进入战斗」**不会直接开局**：先弹出配置界面 —— 左边「匹配模式」（暂未开放）、右边「自定义房间」。
进自定义房间后：中间选**游戏模式 / 地图**（目前只有 歼灭模式·不可复活 / 平原草地），
左右是我方、敌方各 **5 个格子**（玩家默认在左队第 1 格，其余空位），
底部按钮：**添加人机**（下拉选所有存储载具）、**换位到此**（玩家在左队内换位置）、
**邀请朋友**（占位，等联机）、**开始游戏**。点「开始游戏」才真的进战局。

开车 / 开镜 / 开火的操作和测试场完全一样。规则：**一条命，一队全灭那局就结束**（默认名单是玩家 + 4 个人机 vs 5 个人机）；
一队全灭那局就结束；你被打爆了也能留在场上看法队友打完。场地是程序生成的
**500 米见方**缓坡 + 岩石/崖壁掩体（起伏不超过 20°）。队友和敌人是两种轻载具
（`data/vehicles/bot_light.vehicle.txt` / `bot_gunner.vehicle.txt`，改这两个文件就能调人机强度；
**人机的反应速度 / 瞄准精度 / 开火距离** 都在 `data/battle_ai.txt`）。

界面上：**其他载具头顶有血条 + 名字**（我方蓝、敌方红），左上角有**小地图**（蓝点我方、红点敌方）；
敌人平时是**不可见**的，要这样才会被标记出来（全队共享）：

- **自动**：队友（或你）在 **200 米以内**连续看到它 **1 秒**；
- **手动**：把准星对着它、按 **Q**（有 90 像素容差，最远 750 米，要有视线）；
- **命中**：被友方子弹打中也会立刻标记。

标记之后，**全部友方都看不见它 0.5 秒**才重新隐藏。

**声音**：队友和敌人的引擎声、枪声都会响，按**距离衰减**（20 米内满音量、350 米外听不见）
并按**左右声道**定位（声音从画面哪边来就从哪边响）；自己车的声音最响、最居中。

**ESC 暂停菜单**（测试场和对战都一样）：ESC 暂停游戏并弹出菜单 ——
「返回战斗 / 游戏设置（和主界面同一页）/ 自爆（要二次确认）/ 返回主界面」。
返回主界面会把这一场整个拆掉，下次进入是全新的一局。**战斗结束后 ESC 直接回主界面**（不再弹暂停菜单）。

## 从源码运行

1. 装 **Godot 4.7.2**（标准版即可，不需要 .NET 版）。
2. 用 Godot 打开本目录（导入项目），或者命令行：

   ```
   godot --path .
   ```

3. 主界面 → 建造模式拼车 → ESC →「去测试场（先保存）」。

跑测试（不需要编辑器）：

```
godot --headless --path . --script res://tools/run_tests.gd
```

## 目录

| 目录 | 内容 |
| --- | --- |
| `voxel/` | 体素/零件模型层：部件定义、体素体积、建造网格（放置 / 连接 / 镜像） |
| `scripts/` | 游戏层：主界面、建造模式、测试场（轮胎物理 / 武器 / 伤害 / 音频） |
| `data/parts/` | 部件文件（`.part.txt`：形状、数值、连接面、轮子/武器参数） |
| `data/vehicles/` | 保存的载具（`.vehicle.txt`） |
| `data/*.txt` | 用户可手调的表（音频强度、全局手感辅助） |
| `scenes/` | 场景：主界面 / 建造模式 / 测试场 / 人机对战 / 部件实验室 |
| `tools/` | 命令行体检脚本（场地、模型、驾驶、连通性…） |
| `tests/` | 测试套件（`test_*.gd`，见上面的命令） |
| `docs/parts-pipeline.md` | **设计文档**：每一处为什么这么写、踩过哪些坑 |
